# 旅账

一款为日本旅行设计的极简 Android 本地记账应用。无需注册账号，账目保存在手机中，支持文字与语音录入、手动分类、分类统计和 CSV 导出。

## 功能

- 首页仅保留「记账」和「管理」两个入口
- 支持文字输入及系统语音转文字
- 自动从文字中提取消费项目与日元金额
- 保存前可修改项目和金额
- 新账目默认标记为「未分类」
- 在管理页手动归类为餐饮、购物、交通或其他
- 展示总花费、分类花费、分类小计及明细
- 导出 UTF-8 CSV，可使用 Excel、Numbers 等软件打开
- 使用 Android 安全区域，适配居中挖孔屏
- 所有账目均保存在本机

## 下载与安装

请在仓库右侧的 **Releases** 页面下载最新 APK。手机安装时如果提示来源未知，需要为当前浏览器或文件管理器临时允许「安装未知应用」。

最低支持 Android 8.0（API 26）。目前主要针对小米 14 Pro / HyperOS 3 做过兼容调整。

## 使用方法

### 记账

1. 点击首页「记账」。
2. 输入或说出消费内容，例如 `拉面 1200 日元`。
3. 应用会在本地提取项目和金额。
4. 确认或修改信息后保存。

语音输入由手机的系统语音识别引擎提供。首次使用时，需要同时允许旅账和系统语音引擎使用麦克风。系统语音服务是否联网取决于手机厂商的实现。

### 分类与统计

1. 点击首页「管理」。
2. 点击任意账目记录。
3. 手动选择餐饮、购物、交通或其他。
4. 页面会立即重新计算分类金额与小计。

### 导出 CSV

在管理页点击「导出 CSV」，然后在系统文件窗口中选择保存位置。导出字段包括日期时间、消费项目、类别和日元金额。

## 隐私

- 账目、分类和统计数据只存储在本机应用数据中。
- 应用不包含账号系统、广告或数据分析 SDK。
- 应用本身不会上传账目。
- 语音转文字由系统语音引擎处理，可能受其隐私政策和联网设置影响。

详见 [PRIVACY.md](PRIVACY.md)。

## 本地构建

需要：

- JDK 17
- Android SDK 35

克隆项目后，在项目根目录创建 `local.properties`：

```properties
sdk.dir=/你的/Android/sdk/路径
```

然后运行：

```bash
./gradlew assembleDebug
```

生成的 APK 位于：

```text
app/build/outputs/apk/debug/app-debug.apk
```

## 技术说明

- 原生 Android Java
- 无第三方运行时依赖
- 使用 `SharedPreferences + JSON` 保存本地记录
- 使用正则规则在本地提取项目和金额
- 使用 Android `SpeechRecognizer` 接入系统语音识别
- 使用 Storage Access Framework 导出 CSV，无需存储权限

## 旅账首次发布

这是旅账的第一个可用版本，面向日本旅行中的快速日元记账。

### 新增功能

- 极简「记账 / 管理」双入口首页
- 支持文字输入和系统语音输入
- 自动从自然语言中提取消费项目和日元金额
- 保存前可确认和修改识别结果
- 所有账目保存在手机本地
- 管理页展示全部记录和总消费金额
- 支持删除单条记录

### 系统要求

- Android 8.0 或更高版本
- 语音输入需要手机提供可用的系统语音识别服务

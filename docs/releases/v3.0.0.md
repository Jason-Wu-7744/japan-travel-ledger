## 自定义分类与汇率更新

v3.0.0 将管理页扩展为更完整的旅行账本控制台：可以维护自己的消费分类，并查看日元到人民币的实时折算。

### 新增功能

- 管理页新增「管理分类」
- 支持新增、重命名和删除消费分类
- 点击账目归类时，会使用当前自定义分类列表
- 重命名分类会同步更新历史记录
- 删除分类会把对应账目改为未分类
- 管理页新增 JPY 到 CNY 汇率卡片
- 支持实时刷新汇率，也支持手动输入汇率
- 总额、分类小计、按天小计显示人民币折算
- CSV 导出增加汇率和折合人民币列
- 输入人民币、RMB、CNY 或「块」金额时，会按当前汇率折算为日元保存

### 安装说明

可直接覆盖安装 v2.1.1，本地账目会保留。首次打开后，默认分类仍为餐饮、购物、交通和其他；之后可在管理页自由调整。

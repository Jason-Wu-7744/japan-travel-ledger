# v2.1.0 — Manual classification

These are historical feature notes; the distributed APK has not been independently verified against them.

## Changes

- Replace keyword-based classification with explicit user category selection.
- Save new records as uncategorized and allow reclassification.
- Recompute category amounts, counts and subtotals after changes.
- Reset earlier automatic category assignments once during migration.
- Export the final user-selected category.

## Source and installation boundary

Several early tags resolve to the same 2.1.0 source tree; see the [release/source notes](README.md). An in-place update requires a compatible package identifier and signing certificate. Existing APK signatures and update compatibility have not been independently checked. Export records before changing installations; uninstalling removes the local copy, while system backup may restore it later.

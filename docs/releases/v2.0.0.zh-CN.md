## 分类统计与 CSV 导出

本版本扩展管理页，让旅行支出结构更直观，并支持将账目带走分析。

### 新增功能

- 增加餐饮、购物、交通和其他四类消费
- 管理页展示四类金额概览
- 按类别分组展示账目记录
- 显示每个类别的消费笔数和金额小计
- 增加 CSV 导出
- CSV 使用 UTF-8 编码并带有中文兼容标记
- 导出字段包括日期时间、消费项目、类别和金额（日元）
- 通过 Android 系统文件窗口选择保存位置，无需文件存储权限

## 源码与安装边界

这些是历史功能说明，未据此独立验证旧 APK 的实际行为。早期多个版本标签指向同一份 2.1.0 源码，详见[发布与源码说明](README.zh-CN.md)。覆盖安装要求应用包名及签名兼容，此处未验签，不能保证任意附件可直接覆盖。先导出账目；卸载会删除本机数据副本，系统备份可能在之后恢复。
